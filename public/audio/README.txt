Background Music Audio File Information
========================================

Track Title: "Being Watched by Aioka"
Source: https://suno.com/s/RncqaHmMWzJC1w55

To use the custom background track:
Place your MP3 audio file in this directory with either of the following names:
1. background-music.mp3  (i.e., public/audio/background-music.mp3)
2. being-watched-by-aioka.mp3 (i.e., public/audio/being-watched-by-aioka.mp3)

The game will automatically load and loop this track using the HTML5 Audio API:
- Day: Plays quietly in the background at low volume.
- Night: Continues track with increased atmospheric and horror tension.
- Horror locations (Abandoned House, Old Mine, Underground Lab): Volume ducks slightly and subtle environmental acoustics activate.
- Monster appearances: Tension sting plays without cutting the music, ducking briefly before returning.
- If the file is not yet placed, the game gracefully continues using the procedural ambient synthesizer.
